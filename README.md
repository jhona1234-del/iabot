# 🤖 IABoT - Home Assistant AI Assistant

Assistente inteligente autônomo com Bot do Telegram e Google Gemini AI para Home Assistant.

## Recursos
- Integração direta com Telegram Bot API (long polling nativo em Go, sem dependências externas).
- Inteligência Artificial Gemini 2.5 Flash / 1.5 Flash.
- Controle de acesso restrito (apenas administradores autorizam novos usuários com botões inline no Telegram).
- Painel Ingress responsivo para configuração e gestão de usuários.
- Endpoint REST para automações do Home Assistant (`POST /api/send_telegram`).
- Publicação de sensores de estado no Home Assistant Supervisor.
